Project / 01

JusticeAssist AI

Intelligent Decision Support System for Civil Courts.

Problem

Legal case information can be extensive and time-consuming to organize and review. JusticeAssist AI was designed as an intelligent support interface to help organize information and assist with case analysis.

Solution

The system combines a structured web interface, Firebase authentication and Gemini API-powered assistance to provide features such as case analysis, similar case discovery and reports.

Features

  • Judge authentication
  • Two-step authentication
  • Case analysis
  • Similar case discovery
  • Reports
  • Profile
  • AI-assisted decision support

Technology

HTML CSS JavaScript Firebase Gemini API

My Role

Team Leader — Frontend Development & Firebase Authentication/UI.

Important Note

The system is designed as decision support. The final legal decision remains with the human judge.
