# Solairaj R — Full-Stack Software Engineer Portfolio

A cutting-edge, high-performance personal portfolio built with modern web technologies, 3D WebGL rendering, kinetic typography, and fluid micro-animations.

---

## 🛠️ Tech Stack Used

- **Frontend Core**: React 19, JavaScript (ES6+)
- **Build Tool & Bundler**: Vite 8
- **3D Graphics & WebGL**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animation & Physics**: Framer Motion, Canvas-Confetti
- **Styling & Design System**: Tailwind CSS v4, Custom CSS (Glassmorphism, Neon Glow Tokens)
- **Icons**: Lucide React & Handcrafted Vector SVGs
- **Linter & Code Quality**: Oxlint (0 errors, 0 warnings)
- **Deployment**: Render (Static Web Service)

---

## ✨ Design Highlights & Architecture

### 1. 3D Obsidian Monogram Photo Frame
- Handcrafted WebGL 3D model floating and rotating 360° in real-time.
- Features high-definition portrait rendering on the front face and a custom engraved obsidian monogram crest on the reverse with realistic studio lighting and reflections.

### 2. Innovative Cyber Preloader Loading Animation
- **Matrix Text Decryption**: As loading progresses from 0% to 100%, the headline scrambles through cryptographic glyphs before resolving letter-by-letter into `SOLAIRAJ R`.
- **Holographic Reactor Core**: Multi-axis rotating compass dial, hexagonal wireframe, and high-precision HUD percentage readout.
- **Architectural 5-Column Shutter Curtain**: When loaded, the screen divides into 5 vertical obsidian glass columns that slide upward sequentially in a staggered wave.

### 3. Interactive Constellation Canvas & Custom Cursor
- Dynamic HTML5 canvas drawing real-time connected celestial nodes responding to cursor movements.
- Custom precision follower cursor with magnetic hover scaling.

### 4. Compact Section Flow & Rich Micro-Animations
- Carefully balanced section padding (`py-10 sm:py-14`) eliminating dead space between sections.
- Elevated hover lifts, glowing border transitions, and branded technology pills.

### 5. In-App Contact Submission Experience
- Integrated message dispatch with celebratory confetti bursts.
- Immediate in-app transmission confirmation digest without external popups or mailto redirects.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/SOLAIRAJ28/SOLAIRAJ-PORTFOLIO.git

# Navigate into project directory
cd SOLAIRAJ-PORTFOLIO

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
