Interactive Developer & Tech Portfolio Standard

A comprehensive visual, architectural, and technical contract for high-performance developer portfolios featuring Spline 3D interactions, Next.js App Router, neural profile HUD, resilient form validation, and BEXO platform handoff.

Reference: Template-4 (Interactive 3D Tech) Next.js 14 App Router Spline 3D Keyboard & HUD Four Canonical Routes Data-Driven Profile Contract Truthful Handoff

1. Product purpose

Every developer portfolio must answer four high-stakes engineering and hiring questions rapidly: who is this software engineer/system designer, what production systems, open-source work, and architecture prove their technical depth, how can an engineering team contact them directly, and how can they be hired or retained through the platform?

System rule The template preserves the public-site contract. The Next.js App Router and BEXO platform renderer inject real engineer profile data without changing the four canonical routes (/, /portfolio, /contact, /hire-me), navigation order, or hiring handoff behavior.
Do not Hard-code production user data into generic components, add competing secondary navigation systems, bypass honeypot anti-spam measures on contact submission, or duplicate custom billing/checkout forms inside the template.

3. Data contract

Production receives normalized profile objects through window.__BEXO_PROFILE__ or centralized configuration modules (src/data/config.ts, projects.tsx, constants.ts, certifications.ts). Normalized collections

Consumes projectEntries (BaitBlocker, Farm2Pharma, NeuroCare, Git-it-done, NearbyNow, SpinShop), skillEntries (Spline 3D Keyboard, Full-stack, AI/ML, Cloud), and certificateEntries (Coursera, Infosys DSA, Deep Learning) as typed arrays.

Empty collection rule

Supports zero, one, or many items per collection. Any empty section must disappear cleanly from the DOM without leaving dangling headings, empty grids, or broken layout dividers.

Truthful states user.resumeUrl conditionally controls the Resume download CTA button. user.openToHire === true controls the pulsating availability badge. Neither state may ever be hardcoded to true when the profile data specifies false or null.

Home (/)

First viewport rule The above-the-fold viewport must communicate identity, role, and primary CTA without vertical overflow on standard mobile screens (320px–375px). Dynamic viewport units (100svh / 100dvh) guarantee layout stability during mobile address bar transitions.

Portfolio (/portfolio)

Comprehensive technical profile organized in clear logical hierarchy: About & Focus Badges → 3D Interactive Keyboard (Spline) → Falling Skill Cards → Selected Projects Showcase → Certifications Carousel.

3D Spline Keyboard & Skills

Interactive 3D mechanical keyboard powered by Spline runtime. Each keycap reveals skill metadata, proficiency tags, and triggers falling physical cards on mobile viewports.

Project Showcase

Displays rich engineering cards with project badges, tech stack pills, architecture summaries, live preview links, and GitHub repository handoffs.

Contact (/contact)

Resilient form architecture Provides direct email mailto:, phone connection, social channels, and an interactive contact portal. Form inputs include Full Name, Email, optional Phone, and Message.
  • Validates name, email, and message prior to API submission.
  • Validates phone with standard regex only when supplied.
  • Contains a hidden honeypot field (honeypot) that drops automated bot submissions silently.
  • Submits to Next.js API route /api/send (powered by Resend API).
  • Provides accessible live status feedback (loading, success, error) with aria-live="polite".

Hire Me (/hire-me)

Platform handoff Communicates role specialties, engagement terms, and provides a direct handoff action resolving to /hire-me/{handle}. Also offers a fallback email link. Do not recreate custom checkout or payment forms inside the template.

5. Visual and interaction standard

Cyber-Tech Design Language

Deep space canvas (#030014), elevated cyber cards (#0b0f19), neon brand ember (hsl(20, 100%, 70%)), electric cyan (#38bdf8), and cyber purple (#a855f7). Glassmorphism backdrop filters ensure high-end depth.

Responsive Breakpoints

Mobile (320px–640px), Tablet (641px–1024px), Desktop (1025px+). Strictly zero horizontal scroll at 320px CSS width. Fluid typography prevents word breaking.

7. Accessibility and SEO

  • Single descriptive <h1> per page with tailored title and meta description.
  • Accessible navigation with aria-current="page" and accessible mobile menu toggle.
  • Focus-visible rings on all interactive elements (buttons, inputs, links).
  • Informative alt text on profile images, certification credentials, and screenshots.
  • Visible form labels, native input types, real-time error toasts, and aria-live status indicators.
  • Full support for prefers-reduced-motion: reduce to prevent disorientation.
  • Structured Open Graph images and metadata for rich previews on social platforms.

8. Acceptance checklist

  • Home renders Alex Carter identity, designation, portrait HUD, and View Portfolio CTA.
  • Resume button appears only when config.resume / user.resumeUrl exists.
  • Availability badge displays conditionally based on openToHire === true.
  • Portfolio cleanly renders 3D Spline keyboard, skills, projects, and certifications.
  • Empty collections disappear completely without leftover gaps or empty headers.
  • Contact validates name, email, message, and ignores phone when omitted.
  • Honeypot field stops automated submissions without false positives.
  • Hire Me directs users cleanly to /hire-me/{handle} with fallback link.
  • Zero horizontal scrolling at 320px, 375px, 768px, and desktop widths.
  • Keyboard navigation, focus rings, and mobile menu scroll-lock function properly.
  • Next.js TypeScript build compiles cleanly with zero lint or runtime errors.
